# Spec 008: Legacy Docs and Contract Cleanup

## Overview

Clean up the scaffolding edges left by revival: canonical ADR names/index,
contract artifacts for script/config surfaces, and a deliberate policy for
legacy Cowork-era docs and skills.

## SPIDR analysis

**Axis: Rules.** This spec resolves housekeeping rules that affect future
specs and reviews.

## Slices

1. **`008-01 adr-filename-index-normalization`** - Normalize existing ADR files
   and regenerate the decisions index.
2. **`008-02 script-and-config-contracts`** - Add schemas or fixtures for
   script envelopes and config shapes.
3. **`008-03 legacy-cowork-doc-triage`** - Decide what to keep, port, or retire
   from legacy docs and skills.
